# Calculateur de Temps d'Administration

Ce calculateur permet d'estimer rapidement le temps passé chaque semaine sur des tâches administratives répétitives. Il est principalement destiné aux entrepreneurs en construction.

## Contexte

Cet outil est utilisé par Mati dans le cadre de sa prospection commerciale. Il est envoyé aux prospects avant un appel de découverte, afin de recueillir des informations sur leur situation actuelle et d'identifier des pistes d'optimisation.

## Utilisation

1. Ajustez le nombre d'heures hebdomadaires pour chaque tâche en cliquant sur les boutons + et -.
2. Le total d'heures par semaine et par an, ainsi que l'équivalent en dollars, se mettent à jour automatiquement.
3. Cliquez sur "Envoyer mes chiffres à Alexandre" pour générer un email récapitulatif pré-rempli.

Les données saisies sont sauvegardées uniquement en local dans votre navigateur. Elles ne sont pas envoyées ni stockées sur un serveur.

## Technologie

Ce calculateur est une application web statique construite avec :
- HTML pour la structure
- CSS pour la mise en forme
- JavaScript (Vanilla) pour l'interactivité

Le code source est organisé en trois fichiers :
- `index.html` : contenu de la page et appels aux scripts
- `style.css` : règles de style
- `script.js` : logique interactive (calculs, gestion des clics, sauvegarde locale des données)
